Supporting information for: Highly efficient path-integral molecular dynamics simulations with GPUMD using neuroevolution potentials: Case studies on thermal properties of materials doi:[10.48550/arXiv.2409.04430](https://doi.org/10.48550/arXiv.2409.04430)


**Contents of repository**

- MOFs: the GPUMD (Version 3.9) input files for thermal expansion simulation of three MOFs.

- LiH: the GPUMD (Version 3.9.1) input files for thermal expansion simulation of Li1H and Li2H.
